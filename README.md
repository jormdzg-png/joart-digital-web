# Joart Digital — herramientas

**Uso diario (guárdalo en favoritos):** `panel.html` — cotizar, registrar pedido, enviar al cliente (PDF + enlace), pagos, renders y avisos.

**Para el cliente:** `mi-pedido.html?codigo=JD-XXXXX` (estatus en vivo) y `aprobar-render.html`. `seguimiento.html` redirige a Mi pedido (enlaces viejos).

**Desde el panel (pestaña Más):** asistente.

Precios, términos y datos de pago están en `panel.html` (bloques CONFIG y PRECIOS). Backend: Google Apps Script (no está en este repo).
